## Installation Guide

> **Note:** The app is currently not licensed or verified. It requires important permissions, so Google Play Protect blocks the APK installation. For testing, Play Protect need to be turned off temporarily before installation.

### Step 1 — Turn Off Play Protect
Go to **Google Play Store → Profile → Play Protect → Settings** and turn off Play Protect.

### Step 2 — Download APK
Download the NIRBHAYA APK file.

### Step 3 — Install APK
Tap on the downloaded APK and install the application.

### Step 4 — Give Permissions
Grant all the permissions requested by the application.

### Step 5 — Add Emergency Contact
Open the application settings and add an emergency contact.

---

## Required Permissions and Their Uses

| Permission                                          | Use                                                                       |
| ---------------------------------------------------- | -------------------------------------------------------------------------- |
| Location Access                                      | Sharing location                                                          |
| Record Audio / Microphone                            | Voice detection                                                           |
| Make and Manage Calls                                | Calling emergency contact                                                 |
| Send and View SMS                                    | Sending emergency messages to emergency contact                           |
| Background Emergency Call / Display Over Other Apps  | Allows emergency functionality to work in both background and foreground  |

## Functions

### Manual SOS
Allows the user to manually trigger an emergency response.

### AI Voice Detection
Detects emergency/distress voice keywords and triggers the emergency response.

### Area Safety Check
The user enters an area name and gets a risk rank for that area.

### Analyze Surroundings Area
Analyzes the surrounding area and provides a risk score based on factors such as:
* Time
* Nearby facilities
* Hospital
* Police station
* Other nearby safety-related facilities
